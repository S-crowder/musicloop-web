# Musicloop AI — laptop webpage

Open it at **https://s-crowder.github.io/musicloop-web/**

This is the Musicloop AI web app for laptops: split songs, build setlists, and use
**Send to phone** to move songs to the Musicloop Android app.

The app's full source, the Android app and the optional server live in the private
`Musicloop-AI` repository. This repository only hosts the webpage, so it holds no
passwords, accounts or songs. Songs you split stay in your own browser.
