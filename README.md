# Musicloop AI — laptop webpage

Open it at **https://s-crowder.github.io/musicloop-web/**

This is the Musicloop AI player for laptops: import multitrack stems into your library, build setlists,
play them live, and use **Send to phone** to move songs to the Musicloop Android app.

The app's full source, the Android app and the optional server live in the private
`Musicloop-AI` repository. This repository only hosts the webpage, so it holds no
passwords, accounts or songs. Your library stays in your own browser.
